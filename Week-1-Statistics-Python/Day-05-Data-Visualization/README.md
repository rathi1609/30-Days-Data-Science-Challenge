# Day 5: Data Visualization

## Learning Objectives
- Understand the importance of data visualization.
- Learn to create line charts, bar charts, and histograms.
- Create scatter plots and box plots.
- Customize chart titles, labels, and legends.
- Understand how graphs help identify patterns in data.

## Tools
- Python
- Matplotlib
- Seaborn
- Pandas

## Practice
Create a small dataset and visualize it using a bar chart, histogram, and scatter plot.

## Key Learning
Data visualization represents data graphically, making it easier to identify patterns, trends, relationships, and outliers.
