# Day 7: Statistics Mini Project

## Project Title
Exploratory Data Analysis Using Python

## Project Objectives
- Apply descriptive statistics.
- Calculate mean, median, and standard deviation.
- Explore correlation between numerical variables.
- Identify patterns and outliers.
- Create charts to visualize the data.
- Summarize findings from the dataset.

## Tools
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## Project Tasks
1. Load a CSV dataset using Pandas.
2. Check the dataset's rows, columns, and data types.
3. Handle missing values if necessary.
4. Calculate descriptive statistics.
5. Explore correlations between numerical columns.
6. Create histograms, bar charts, and scatter plots.
7. Write a short summary of the findings.

## Expected Outcome
A Jupyter Notebook containing data analysis, visualizations, and conclusions.

## Key Learning
Exploratory Data Analysis (EDA) helps us understand a dataset, discover patterns, and prepare data for further analysis or machine learning.
