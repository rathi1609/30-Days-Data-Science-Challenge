# Day 3: Probability and Distributions

## Learning Objectives
- Understand basic probability.
- Learn normal distribution.
- Understand binomial distribution.
- Learn about skewed distributions.
- Visualize probability distributions using Python.

## Tools
- Python
- NumPy
- Matplotlib
- SciPy

## Practice
Generate random data using Python and visualize its distribution using a histogram.

## Key Learning
Probability measures the likelihood of an event. Probability distributions describe the possible values of a random variable and their probabilities.
