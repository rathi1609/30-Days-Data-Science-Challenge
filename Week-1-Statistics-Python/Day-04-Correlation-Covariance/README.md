# Day 4: Correlation and Covariance

## Learning Objectives
- Understand correlation and covariance.
- Learn positive and negative correlation.
- Understand the relationship between two variables.
- Calculate correlation using Pandas.
- Visualize relationships using scatter plots.

## Tools
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn

## Practice
Create a small dataset with two numerical variables. Calculate their correlation and covariance using Pandas, then visualize their relationship using a scatter plot.

## Key Learning
Correlation measures the strength and direction of the relationship between two variables. Covariance indicates whether two variables tend to change in the same or opposite directions.
