# Day 6: NumPy and Pandas Basics

## Learning Objectives
- Understand NumPy arrays.
- Learn basic array operations.
- Understand Pandas Series and DataFrames.
- Learn to load CSV files using Pandas.
- Practice selecting, filtering, and summarizing data.

## Tools
- Python
- NumPy
- Pandas
- Jupyter Notebook

## Practice
Create a NumPy array and perform basic calculations. Then create a Pandas DataFrame, filter rows, and calculate summary statistics.

## Key Learning
NumPy helps perform numerical calculations efficiently, while Pandas helps organize, manipulate, and analyze structured data.
