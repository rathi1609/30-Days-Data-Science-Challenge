# Day 2: Descriptive Statistics

## Learning Objectives
- Understand mean, median, and mode.
- Learn variance and standard deviation.
- Understand quartiles and outliers.
- Calculate summary statistics using Pandas.

## Tools
- Python
- Pandas
- NumPy
- Matplotlib

## Practice
Create a small dataset and calculate its mean, median, mode, variance, and standard deviation using Python.

## Key Learning
Descriptive statistics help us summarize and understand the main characteristics of a dataset.
